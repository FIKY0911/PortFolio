# i18n (Internationalization)

**File:** `frontend/src/i18n/index.js`

## Deskripsi
Konfigurasi multi-language menggunakan `react-i18next` untuk mendukung 2 bahasa: Indonesia (ID) dan English (EN).

## Struktur File

```
frontend/src/i18n/
├── index.js           # Konfigurasi i18n
├── locales/
│   ├── id.json       # Terjemahan Indonesia
│   └── en.json       # Terjemahan English
```

## Konfigurasi

### `index.js`
```javascript
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import id from './locales/id.json'
import en from './locales/en.json'

const savedLanguage = localStorage.getItem('language') || 'id'

i18n.use(initReactI18next).init({
  resources: {
    id: { translation: id },
    en: { translation: en },
  },
  lng: savedLanguage,           // Bahasa default
  fallbackLng: 'id',            // Fallback jika translation tidak ada
  interpolation: {
    escapeValue: false,         // React sudah escape by default
  },
})

// Save ke localStorage saat bahasa berubah
i18n.on('languageChanged', (lng) => {
  localStorage.setItem('language', lng)
})
```

## Cara Penggunaan

### 1. Import Hook
```javascript
import { useTranslation } from 'react-i18next'
```

### 2. Gunakan di Component
```javascript
function HeroSection() {
  const { t, i18n } = useTranslation()
  
  return (
    <div>
      <h1>{t('hero.greeting')}</h1>
      <p>{t('hero.description')}</p>
      
      {/* Ganti bahasa */}
      <button onClick={() => i18n.changeLanguage('en')}>
        English
      </button>
    </div>
  )
}
```

### 3. Nested Translation
```javascript
// Akses nested object
t('hero.greeting')        // "Halo, Saya Fiky!☺️"
t('nav.home')             // "Beranda"
t('skills.noSkills')      // "Tidak ada skill tersedia"
```

### 4. Dynamic Translation
```javascript
// Dengan variable
const { t } = useTranslation()
const key = 'hero.greeting'
t(key)  // "Halo, Saya Fiky!☺️"
```

### 5. Cek Bahasa Aktif
```javascript
const { i18n } = useTranslation()
console.log(i18n.language)  // "id" atau "en"
```

## Language Switcher Component

**File:** `frontend/src/components/LanguageSwitcher.jsx`

```javascript
import { useTranslation } from 'react-i18next'

const LanguageSwitcher = () => {
  const { i18n } = useTranslation()
  const currentLang = i18n.language

  const toggleLanguage = () => {
    const newLang = currentLang === 'id' ? 'en' : 'id'
    i18n.changeLanguage(newLang)
  }

  return (
    <button onClick={toggleLanguage}>
      {currentLang === 'id' ? '🇮🇩 ID' : '🇬🇧 EN'}
    </button>
  )
}
```

## Integrasi dengan API

Saat bahasa berubah, `useApi` hook otomatis:
1. Detect perubahan bahasa via event `languageChanged`
2. Clear cache untuk endpoint yang di-fetch
3. Refetch data dengan header `Accept-Language` baru
4. Backend return data sesuai bahasa

```javascript
// useApi.js
i18n.on('languageChanged', () => {
  cache.delete(cacheKey)
  fetchData(true)
})
```

## LocalStorage Persistence

Bahasa yang dipilih disimpan di localStorage:
```javascript
localStorage.setItem('language', 'en')
localStorage.getItem('language')  // "en"
```

Saat user refresh page, bahasa tetap sama.

## Best Practices

### 1. Gunakan Key yang Deskriptif
```javascript
// ❌ Bad
t('text1')
t('btn')

// ✅ Good
t('hero.greeting')
t('nav.home')
```

### 2. Grouping by Feature
```json
{
  "hero": { ... },
  "nav": { ... },
  "footer": { ... },
  "skills": { ... }
}
```

### 3. Fallback untuk Missing Translation
```javascript
t('missing.key', 'Default Text')
```

### 4. Pluralization (jika diperlukan)
```json
{
  "items": "{{count}} item",
  "items_plural": "{{count}} items"
}
```

```javascript
t('items', { count: 1 })   // "1 item"
t('items', { count: 5 })   // "5 items"
```

## Troubleshooting

### Translation tidak muncul
- Cek apakah key ada di file JSON
- Cek typo di key
- Pastikan file JSON valid (tidak ada trailing comma)

### Bahasa tidak berubah
- Cek apakah `i18n.changeLanguage()` dipanggil
- Cek console untuk error
- Clear localStorage dan coba lagi

### Data API tidak berubah saat ganti bahasa
- Pastikan `useApi` hook sudah listen event `languageChanged`
- Cek network tab, pastikan header `Accept-Language` terkirim
- Cek backend sudah implement translation
